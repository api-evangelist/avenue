# Avenue

> Avenue was an operations observability and alerting platform for operations, RevOps
> and support teams. It connected to the data systems a business already ran on
> (Postgres, MySQL, MongoDB, Snowflake, BigQuery, Redshift, Databricks, Airtable,
> Google Sheets, Salesforce, HubSpot, Zendesk, Intercom, a REST API endpoint), watched
> for issues with custom SQL-backed monitors and thresholds, and routed alerts through
> playbooks into Slack, Zendesk, Twilio, Front, Linear, Asana, Notion, Trello,
> Telegram, WhatsApp, SendGrid, Customer.io or a customer webhook. Founded in 2021 by
> Justin Bleuel and Jeff Barg (ex-Uber Eats, ex-Amazon); backed by Y Combinator, Slack
> Fund, Accel, Flexport, Lachy Groom and Elad Gil. **Acquired by Clay in January
> 2025.** The product is no longer operating.

**Status for agents: there is no callable Avenue API.** Avenue never published an
OpenAPI, GraphQL, MCP or A2A surface, and the application itself is offline. Do not
attempt to call an Avenue endpoint — none is routed.

## Machine-readable surfaces

None published. Probed and missed on every host:

- No OpenAPI or Swagger (`/openapi.json`, `/swagger.json`, `/api-docs` — 404 on avenue.app, 404 on app.useavenue.com)
- No GraphQL endpoint
- No MCP server
- No A2A agent card (`/.well-known/agent-card.json` and `/.well-known/agent.json` — 404)
- No `llms.txt` served by the provider (`https://avenue.app/llms.txt` — 404); this file is generated by API Evangelist
- No `/.well-known/` document of any kind returned 200

## The one event surface Avenue did document

- [Webhooks](https://avenue.app/integrations/webhooks): incoming webhooks let third-party services push data into Avenue; outgoing webhooks send an occurrence-based payload from SQL query triggers over HTTPS to a customer endpoint. No event catalog, payload schema or signature scheme was ever published.
- [REST API as a data source](https://avenue.app/integrations/rest-api): Avenue could *consume* an external REST endpoint as a monitored data source. This is Avenue calling your API — not an Avenue API you can call.
